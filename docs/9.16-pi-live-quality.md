在已有 `tests/camera_detect_test.cpp` 增加 `--sample-dir`，修改按组标注 `[Pi实图]`。不带参数时不保存图；显式启用时：

### 第三步：仍用基线配置采集三组原图（待编译成功）

先让相机正常对着亮着的板，保持现有曝光、焦距和位置，暂不同时调整。若旧程序还占着相机，用原SSH终端Ctrl+C结束它。继续使用原浏览器地址 `http://192.168.1.105:8080/`。

以下变量定义不启动程序；以 `"$task_build/hailo_camera_test"` 开头的一组才真正启动相机和检测。每行末尾 `\` 代表命令接下一行，最后一行没有它。运行25秒自动停止，首张有效图后约5/10/15秒各存一组，出现 `saved_sample=1/2/3`；提前Ctrl+C会少存。使用时间戳创建不重复目录，不需要删除旧记录。

```bash
task_sp25='/home/xiao/sp_vision_25-main'
task_build="$task_sp25/build/pi-hailo"
task_samples="$task_build/live-quality-$(date +%Y%m%d-%H%M%S)"
cd "$task_build"
"$task_build/hailo_camera_test" \
  --camera-config="$task_sp25/configs/camera.yaml" \
  --detector-config="$task_sp25/configs/pi_hailo.yaml" \
  --seconds=25 \
  --preview-port=8080 \
  --sample-dir="$task_samples"
echo "live_exit_code=$?"
printf 'sample_directory=%s\n' "$task_samples"
```

没有取得原图前，不断言角点错误的根因，不直接把画面增强、灯条修正、换模型或训练当作已验证修复。若同图对照仍错，继续核对该帧解码/NPU输出和原参考结果，再决定改解码还是模型/采图。当前没有改 Tracker/Solver/Aimer、标定或C板协议；这些主线项目继续保留。
