## 2. 修改、原因和边界

所有新代码按组标记 `[Pi预览]`，只涉及现有测试入口和预览辅助头文件：

| 文件 | 修改及作用 |
| --- | --- |
| `tests/camera_detect_test.cpp` | 增加 `--preview-port`，默认 0 表示关闭；开启时仍使用同一相机、同一 YOLO 实例和同一帧的 Armor 结果。端口先绑定，出错时不再打开设备。 |
| `tests/live_preview.hpp` | 新增只供该入口使用的 Linux HTTP 预览类。绿线连接四角点、黄点标角点，文字显示模型颜色/编号/大小板和置信度。网页显示帧序号及框数，图像停更或断开时隐藏旧图并提示等待。 |
| 同一辅助头文件 | 最多每秒 10 次复制画面并编码 JPEG；只保留最新 JPEG。网络在独立线程处理，读取/发送有期限，退出检查可中断等待；慢客户端不保留相机槽位。无框时发布新画面，不继续画旧框。 |

JPEG 编码与少量绘制发生在检测完成后，因此预览会增加 CPU 工作量，日志明确标记 `mode=live_preview`，不能用这一模式直接复现此前无预览性能。不开预览时不创建监听端口、不绘制或编码图像，原检测流程保留。

不修改相机驱动、两份 YAML、检测器、阈值、模型、Tracker/Solver/Aimer 或通信协议。现有目标已链接 imgproc/imgcodecs/Threads，无需改 CMake、安装 Web 框架或在 Pi 上开启桌面。
