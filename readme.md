# SP25 · 树莓派 5 + Hailo-8L

基于同济 SuperPower SP25，适配树莓派、Hailo NPU、海康相机和青大 C 板通信。更新：2026-09-27。

## 当前状态

- 主要入口：`standard`、`standard_readonly`，均支持浏览器预览；只读入口强制禁止串口发送。
- 相机、Hailo 检测和 C 板姿态接收已有实测记录；Shooter 接入和正式入口预览已提交，真实闭环、外参及长稳仍待验收。
- 步兵 4 等配置的共用硬件参数已按步兵 3 整理；配置统一不等于对应兵种已适配。
- 哨兵、UAV、MPC、打符入口尚未完成当前平台适配；英雄、工程没有完整专用入口。原哨兵其他相机、导航及相关接口按原方案保留。

## 目录与维护

| 目录 | 用途 |
| --- | --- |
| `src/`、`tasks/` | 程序入口与算法模块 |
| `io/`、`tools/` | 设备接口与公共工具 |
| `configs/`、`calibration/` | 参数与标定程序 |
| `tests/`、`docs/` | 测试入口与历史记录 |
| `build/`、`logs/` | 本机构建、临时检查与日志，不作为源码提交 |

电脑 Git 是源码基准；临时探针放 `build/`。Pi 使用同一提交的完整源码和校验清单，校验通过后再记录为同步完成。
`autostart.sh` 当前仅用于持续相机诊断，不代表完整程序已注册开机服务。
